# Улучшения героев

Улучшения героев — это постоянные усиления, применяемые к героям через исследования в **Алтаре героев**. Каждое улучшение повышает характеристики связанного героя или даёт ему новые атрибуты.

## Определение улучшения героя

| Свойство                    | Тип значения                                                   | Описание                                                                                   | Пример значения                                            |
| --------------------------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------ | ---------------------------------------------------------- |
| id                          | int                                                            | Идентификатор улучшения                                                                    | 1                                                          |
| hero_id                     | int                                                            | Идентификатор героя, получающего улучшение                                                 | 1                                                          |
| altar_of_heroes_research_id | int                                                            | Идентификатор исследования Алтаря героев, открывающего это улучшение                       | 1                                                          |
| stats                       | [interface:Stats](./interfaces/stats.md) \| null               | Бонус к боевым характеристикам (здоровье, атака и т. д.)                                   | [Определение](./interfaces/stats.md#definition-example)    |
| attributes                  | [array:interface:Attribute](./interfaces/attribute.md) \| null | Бонус к особым атрибутам. Значения суммируются, если есть несколько улучшений одного типа. | [Определение](./interfaces/attribute.md#definition-example) |

## Пример определения

```json
{
    "id": 1,
    "hero_id": 1,
    "altar_of_heroes_research_id": 1,
    "stats": {
        "health": 500,
        "attack": 75,
        "initiative": 110,
        "speed": 4,
        "range": null
    },
    "attributes": null
}
```
