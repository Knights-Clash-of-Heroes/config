# Настройки королевства

Этот файл определяет глобальные свойства королевства игрока, которые не привязаны к конкретной сущности или служат начальным значением (базовой линией).

| Свойство                 | Тип | Описание                                                                    | Пример значения |
| ------------------------ | --- | --------------------------------------------------------------------------- | --------------- |
| initial_occupation_limit | int | Начальный лимит заселения (жилья), который королевство поддерживает для юнитов. | 10          |

## Пример определения

```json
{
    "initial_occupation_limit": 8
}
```
