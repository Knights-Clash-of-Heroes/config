# Исследования Замка

Исследования Замка (`castle_researches`) отвечают за глобальные улучшения и обновления зданий вашего королевства. Обычно они оплачиваются несколькими видами базовых ресурсов и предметов. Эти исследования навсегда повышают вашу защиту и продуктивность.

| Свойство            | Тип                                            | Описание                                                                             | Пример значения    |
| ------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------ | ------------------ |
| id                  | int                                            | Уникальный идентификатор исследования.                                               | 1                  |
| name                | string                                         | Название исследования.                                                               | "Reinforced Walls" |
| name_key            | string                                         | Ключ перевода названия.                                                              | "castle_1_name"    |
| price               | [array:interface:Price](./interfaces/price.md) | Необходимая стоимость в ресурсах и/или общих предметах.                              | [...]              |
| research_time       | int                                            | Длительность исследования в секундах.                                                | 7200               |
| building_upgrade_id | int \| null                                    | Если не null, активирует улучшение указанного здания (`building_upgrades`).          | 1                  |
| unlock_building_id  | int \| null                                    | Если не null, позволяет приобрести указанное новое здание (`buildings`).             | null               |

## Пример определения

```json
{
    "id": 1,
    "name_key": "castle_research_1_name",
    "name": "Reinforce Walls",
    "price": [
        {
            "type": "resource",
            "resource_id": 3,
            "quantity": 300
        }
    ],
    "research_time": 3600,
    "building_upgrade_id": 2,
    "unlock_building_id": null
}
```
