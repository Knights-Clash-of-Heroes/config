# Участки земли королевства

Участки земли — это части территории королевства. Карта королевства состоит из сетки таких участков, которые могут быть стартовой территорией или покупными расширениями.

## Размер участка земли королевства

Размер каждого участка земли задаётся глобально в конфигурации и определяет, сколько «клеток» для зданий помещается в одном участке.

| Свойство | Тип | Описание                  |
| -------- | --- | ------------------------- |
| width    | int | Ширина участка в клетках  |
| height   | int | Высота участка в клетках  |

## Структура участка земли королевства

| Свойство     | Тип значения                                           | Описание                                                  | Пример значения                                            |
| ------------ | ------------------------------------------------------ | --------------------------------------------------------- | ---------------------------------------------------------- |
| id           | int                                                    | Уникальный идентификатор участка земли                    | 1                                                          |
| is_expansion | boolean                                                | Если true, игрок должен купить участок, чтобы им пользоваться | true                                                    |
| position     | [interface:Position](./interfaces/position.md)         | Позиция (столбец и строка) участка на карте королевства   | [Definition](./interfaces/position.md#definition-example)  |
| price        | [array:interface:Price](./interfaces/price.md) \| null | Стоимость, необходимая для открытия расширения            | [Definition](./interfaces/price.md#definition-example)     |

## Пример определения

```json
{
    "id": 10,
    "is_expansion": true,
    "position": {
        "x": 0,
        "y": 0
    },
    "price": [
        {
            "type": "resource",
            "resource_id": 1,
            "quantity": 1000
        }
    ]
}
```
