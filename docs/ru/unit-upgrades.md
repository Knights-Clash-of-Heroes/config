# Улучшения юнитов

Улучшения юнитов предназначены для усиления игровых юнитов. Их можно получить несколькими способами: через Арсенал, Лавку дракона и вкладку улучшений в Магазине. Свойства следующие:

| Свойство            | Тип значения                                                   | Описание                                                                                                                          | Пример значения                                            |
| ------------------- | -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| id                  | int                                                            | Идентификатор улучшения                                                                                                           | 1                                                          |
| unit_id             | int                                                            | Идентификатор юнита                                                                                                               | 1                                                          |
| arsenal_research_id | int \| null                                                    | Идентификатор исследования, которое можно провести для этого юнита                                                                | 1                                                          |
| stats               | [interface:Stats](./interfaces/stats.md) \| null               | Прирост боевых характеристик юнита: здоровья, урона, инициативы, скорости и дальности                                              | [Definition](./interfaces/stats.md#definition-example)     |
| attributes          | [array:interface:Attribute](./interfaces/attribute.md) \| null | Прирост особых атрибутов юнита. Если применяется несколько атрибутов одного типа, их значения суммируются.                         | [Definition](./interfaces/attribute.md#definition-example) |

## Пример определения

```json
{
    "id": 1,
    "unit_id": 1,
    "arsenal_research_id": 1,
    "stats": {
        "health": 10,
        "attack": 5,
        "initiative": 2,
        "speed": 3,
        "range": null
    },
    "attributes": [
        {
            "attribute_id": 1,
            "value": 10
        }
    ]
}
```
