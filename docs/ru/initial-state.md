# Начальное состояние

`initial_state.json` описывает королевство совершенно нового игрока. Теперь он следует **формату оригинальной игры**: той же структуре, которую оригинальный сервер отправлял в ответе `initialize` (JSON, как и остальные оригинальные данные; единственные XML-файлы оригинальной игры — `client_config`, `server_config`, `levels` и `billing`, и ни один из них не хранит начальное состояние).

> [!WARNING]
> **Идентификаторы в этом файле — id оригинальной игры, которых нет в `config.json`.**
>
> `config.json` был написан до того, как нашлись оригинальные файлы игры (разработчики нашли их только сейчас, почти через 5 лет после закрытия игры) и использует собственные последовательные id. Оригинальная игра определяет каждое здание и каждого юнита по id из своей базы данных (например, `490400668` для Замка). Два пространства id несовместимы. Этот репозиторий связывает их небольшой таблицей соответствий [`originalEntityIds`](../../src/original-ids.ts) — только для сущностей начального города. Всё, чего нет в этой таблице, пока нельзя проверить.

Предыдущий формат (`kingdom.resources`, `kingdom.buildings`, `kingdom.units` с `chunk_id` + `position`) был черновиком и удалён; он остался в истории git.

## Формат

| Свойство | Тип                        | Источник              | Описание                                                          |
| -------- | -------------------------- | --------------------- | ----------------------------------------------------------------- |
| player   | Player                     | оценка                | Начальный уровень и ресурсы.                                      |
| entities | словарь `sceneId` → Entity | **оригинал (`map`)**  | Начальный город: уже размещённые здания и юниты.                  |
| options  | `{ landLimit }`            | **оригинал (`map`)**  | `landLimit` — число участков земли, которыми может владеть игрок. |

### Player

| Свойство   | Тип | Описание                      |
| ---------- | --- | ----------------------------- |
| level      | int | Начальный уровень.            |
| experience | int | Начальный опыт.               |
| money      | int | Золото.                       |
| cash       | int | Кристаллы (премиум-валюта).   |
| wood       | int | Дерево.                       |
| stone      | int | Камень.                       |
| iron       | int | Железо.                       |

Энергия не хранится: оригинальная игра начинает с максимума, его вычисляет сервер.

### Entity

Ровно тот объект, который оригинальный клиент вливает в свой мир (`WorldManageUtils.mergeMapData`).

| Свойство | Тип | Описание                                                                                          |
| -------- | --- | ------------------------------------------------------------------------------------------------- |
| id       | int | Id сущности в **оригинальной** базе данных. См. [соответствия](#соответствие-оригинальных-id).    |
| sceneId  | int | Уникальный id размещённого объекта. Должен совпадать с ключом записи в `entities`.                |
| owner    | int | Код владельца в оригинальной карте (`1` — объекты игрока, `3` — Алтарь и Рынок). Значение `3` не подтверждено. |
| x, y     | num | Позиция на сетке города.                                                                          |
| dir      | int | Код ориентации оригинального клиента (`0` или `6` в начальном городе).                            |

## Соответствие оригинальных id

| Оригинальный id | Оригинальное название | Название        | Сущность в config          | Уверенность |
| --------------- | --------------------- | --------------- | -------------------------- | ----------- |
| `490400668`     | Замок                 | Замок           | здание `1` (Citadel)       | да          |
| `335153735`     | Казарма               | Казарма         | здание `2`                 | да          |
| `482206421`     | Палатка               | Палатка         | здание `3` (Pavillion)     | **нет**, только по названию |
| `965182906`     | Ферма                 | Ферма           | здание `5`                 | да          |
| `1212037112`    | Алтарь героев         | Алтарь героев   | здание `13`                | да          |
| `1095215970`    | Рынок                 | Рынок           | здание `14`                | да          |
| `793331619`     | Grunt: Копейщик 1     | Копейщик        | юнит `1` (Militiaman)      | да          |

`npm run validate` завершается ошибкой, если сущность использует оригинальный id, которого нет в этой таблице, или если соответствующей сущности нет в `config.json`.

## Что проверено, а что нет

- **Проверено (прочитано из восстановленного файла `map`):** 9 сущностей начального города (Алтарь, Замок, Ферма, три Копейщика, Казарма, Рынок, Палатка), их позиции и `landLimit` `10`.
- **Оценка:** всё в `player`. Значения взяты из предыдущего черновика этого файла; оригинальные стартовые значения находятся в `server_config`, который **не был восстановлен**. Не считайте их оригинальными.
- **Пока не охвачено:** остальные блоки оригинального ответа `initialize` (`storage`, `playerStats`, `inventory`, `unlocks`, `heroes`, `quests`, ...). Клиент читает их с сервера; см. `recovery/PROTOCOLO.md` в основном рабочем пространстве. Это игровое состояние во время работы, а не часть статического стартового файла, и собирает его сервер.

## Пример

```json
{
    "player": { "level": 1, "experience": 0, "money": 5000, "cash": 10, "wood": 50, "stone": 0, "iron": 0 },
    "entities": {
        "828": { "id": 490400668, "sceneId": 828, "owner": 1, "x": 15, "y": -4, "dir": 0 }
    },
    "options": { "landLimit": 10 }
}
```
