# Руны

Руны — магические предметы, позволяющие творить заклинания без свитков этих заклинаний. Они изготавливаются в Гномьей кузнице, и для каждого типа задан лимит рун. Руны разделены по стихиям, которые регистрируются в конфигурации со следующими свойствами:

| Свойство | Тип    | Описание                       |
| -------- | ------ | ------------------------------ |
| id       | int    | Уникальный идентификатор руны. |
| limit    | int    | Лимит рун каждого типа.        |
| name     | string | Название руны.                 |
| name_key | string | Ключ названия руны.            |

## Пример определения

```json
{
    "id": 1,
    "limit": 6,
    "name": "Flame Rune",
    "name_key": "rune_1_name"
}
```
