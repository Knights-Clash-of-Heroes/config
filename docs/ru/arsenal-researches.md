# Исследования Арсенала

Исследования Арсенала (`arsenal_researches`) направлены на улучшение обычных юнитов: они дают пассивные бонусы (более сильные юниты) или открывают новых юнитов в игре. Оплачиваются обычными ресурсами и игровыми предметами.

| Свойство        | Тип                                            | Описание                                                        | Пример значения  |
| --------------- | ---------------------------------------------- | --------------------------------------------------------------- | ---------------- |
| id              | int                                            | Уникальный идентификатор исследования.                          | 1                |
| name            | string                                         | Название исследования.                                          | "Iron Weapons"   |
| name_key        | string                                         | Ключ перевода названия.                                         | "arsenal_1_name" |
| price           | [array:interface:Price](./interfaces/price.md) | Стоимость исследования в ресурсах и предметах.                  | [...]            |
| research_time   | int                                            | Время, необходимое для завершения исследования, в секундах.     | 3600             |
| unit_upgrade_id | int \| null                                    | ID улучшения юнита (`unit_upgrades`), которое будет применено.  | 1                |
| unlock_unit_id  | int \| null                                    | ID нового открываемого юнита (`units`), если применимо.         | null             |

## Пример определения

```json
{
    "id": 1,
    "name_key": "arsenal_research_1_name",
    "name": "Dark Iron",
    "price": [
        {
            "type": "resource",
            "resource_id": 1,
            "quantity": 100
        },
        {
            "type": "item",
            "item_id": 12,
            "quantity": 5
        }
    ],
    "research_time": 3600,
    "unit_upgrade_id": 1,
    "unlock_unit_id": null
}
```
