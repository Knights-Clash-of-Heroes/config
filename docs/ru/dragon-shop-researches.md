# Исследования Магазина драконов

Исследования Магазина драконов (`dragon_shop_researches`) — это особые, роскошные или глобально выгодные (элитные) улучшения зданий и юнитов. Так как это премиум-магазин игры, стоимость оплачивается исключительно **кристаллами** (премиум-ресурс).

| Свойство            | Тип                                            | Описание                                                             | Пример значения   |
| ------------------- | ---------------------------------------------- | -------------------------------------------------------------------- | ----------------- |
| id                  | int                                            | Уникальный идентификатор улучшения.                                  | 1                 |
| name                | string                                         | Название исследования.                                               | "Ancient Lore"    |
| name_key            | string                                         | Ключ перевода названия.                                              | "dragon_1_name"   |
| price               | [array:interface:Price](./interfaces/price.md) | Стоимость улучшения. **Должна взиматься в кристаллах.**              | [...]             |
| research_time       | int                                            | Длительность процесса в секундах.                                    | 3600              |
| building_upgrade_id | int \| null                                    | Активирует суперулучшение указанного конкретного здания.             | 1                 |
| unit_upgrade_id     | int \| null                                    | Активирует суперулучшение указанного юнита.                          | null              |

## Пример определения

```json
{
    "id": 1,
    "name_key": "dragon_research_1_name",
    "name": "Ancient Lore",
    "price": [
        {
            "type": "resource",
            "resource_id": 2,
            "quantity": 300
        }
    ],
    "research_time": 3600,
    "building_upgrade_id": 5,
    "unit_upgrade_id": null
}
```
