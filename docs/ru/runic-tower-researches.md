# Исследования Рунической башни

Исследования Рунической башни (`runic_tower_researches`) направлены на улучшение системы активных способностей (заклинаний) и на усиление рун игры. Они оплачиваются ресурсами и магическими предметами, собранными игроком.

| Свойство        | Тип                                            | Описание                                                   | Пример значения |
| --------------- | ---------------------------------------------- | ---------------------------------------------------------- | --------------- |
| id              | int                                            | Уникальный идентификатор исследования.                     | 1               |
| name            | string                                         | Название исследования.                                     | "Fire Magic"    |
| name_key        | string                                         | Ключ перевода названия.                                    | "runic_1_name"  |
| price           | [array:interface:Price](./interfaces/price.md) | Необходимая стоимость в ресурсах и предметах.              | [...]           |
| research_time   | int                                            | Длительность процесса исследования в секундах.             | 3600            |
| unlock_spell_id | int \| null                                    | ID открываемого заклинания (`spells`).                     | 1               |
| unlock_rune_id  | int \| null                                    | ID типа руны (`runes`), которая открывается или улучшается. | null           |

## Пример определения

```json
{
    "id": 1,
    "name_key": "runic_research_1_name",
    "name": "Arcanist Magic",
    "price": [
        {
            "type": "resource",
            "resource_id": 2,
            "quantity": 50
        }
    ],
    "research_time": 1800,
    "unlock_spell_id": 2,
    "unlock_rune_id": null
}
```
