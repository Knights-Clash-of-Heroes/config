# Ресурсы

Ресурсы — основа игры: они нужны для строительства зданий, обучения юнитов, проведения исследований и продвижения по игре. Это и монеты, и строительные материалы, и опыт, и энергия.

| Свойство                 | Тип                | Описание                                                                                                                      | Пример значения          |
| ------------------------ | ------------------ | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------ |
| id                       | int                | Уникальный идентификатор ресурса                                                                                              | 1                        |
| name                     | string             | Понятное название ресурса (по умолчанию на английском)                                                                        | "Gold"                   |
| name_key                 | string             | Ключ перевода названия ресурса                                                                                                | "resource_1_name"        |
| description              | string             | Понятное описание ресурса                                                                                                     | "Money: the more..."     |
| description_key          | string             | Ключ перевода описания ресурса                                                                                                | "resource_1_description" |
| initial_storage_capacity | int \| "unlimited" | Начальная глобальная вместимость хранилища. Если "unlimited", запас ресурса не ограничен.                                     | 5000                     |
| can_overflow             | boolean            | Если true, награды (например, из сундуков) могут превышать максимальную вместимость хранилища без потери ресурса.             | true                     |
| regeneration_time        | int \| null        | Время в секундах, за которое ресурс восстанавливает заданное количество. Если null, ресурс сам не восстанавливается.          | 3600                     |
| regeneration_quantity    | int \| null        | Количество ресурса, автоматически создаваемое в каждом цикле, заданном в `regeneration_time`.                                 | 1                        |

## Пример определения

```json
{
    "id": 1,
    "name": "Gold",
    "name_key": "resource_1_name",
    "description_key": "resource_1_description",
    "description": "Money: the more you have, the better!",
    "initial_storage_capacity": 5000,
    "can_overflow": false,
    "regeneration_time": null,
    "regeneration_quantity": null
}
```
