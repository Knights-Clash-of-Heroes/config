# Тип цели

Тип цели определяет, поражает ли заклинание, способность, юнит или здание одну цель, область или цепочку целей:

| Название | Значение | Описание                                                                                                          |
| -------- | -------- | ----------------------------------------------------------------------------------------------------------------- |
| Одиночная | single  | Поражает только одну цель, доступно для юнитов, зданий и заклинаний                                               |
| Область  | area     | Поражает область, доступно для юнитов, зданий и заклинаний; значение дальности должно быть нечётным, чтобы у области был центр |
| Цепочка  | chain    | Поражает цепочку целей, доступно только для заклинаний                                                            |
