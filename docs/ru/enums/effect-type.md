# Тип эффекта

Тип эффекта определяет, как будет применяться механическое воздействие.

| Название   | Значение    | Описание                                                                                             |
| ---------- | ----------- | ---------------------------------------------------------------------------------------------------- |
| Временный  | `temporary` | Действует заданное число ходов и влияет только на целевой юнит.                                      |
| Аура       | `aura`      | Активирует [ауру](../interfaces/aura.md) вокруг излучающего юнита на несколько ходов.                |
