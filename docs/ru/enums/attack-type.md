# Тип атаки

Тип атаки используется для запуска способностей и пассивных эффектов атакующего, а также пассивных негативных эффектов на цели. Возможные значения:

| Название    | Значение | Описание                                                                                             |
| ----------- | -------- | ---------------------------------------------------------------------------------------------------- |
| Ближний бой | melee    | Физическая атака, обычно наносится тяжёлой пехотой и бронированными юнитами                          |
| Стрела      | arrow    | Атака из лука, наносится лучниками и башнями лучников                                                |
| Осада       | siege    | Атака дротиками, наносится баллистами                                                                |
| Магия       | magic    | Магическая атака, наносится магами, как стреляющими снарядами, так и атакующими в ближнем бою        |
