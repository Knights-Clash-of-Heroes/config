# Тип юнита

Тип юнита — это категория, определяющая, чем является юнит, чтобы можно было вывести, могут ли на него влиять активные и пассивные способности:

| Название       | Значение      | Описание                                                                                                                         |
| -------------- | ------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Пеший          | on_foot       | Пеший солдат, обычно тяжёлая пехота, некоторые бронированные юниты, маги                                                         |
| Конный         | mounted       | Конный солдат, обычно на лошади; включает всех рыцарей и других солдат, сидящих на животных, например на снежном леопарде        |
| Осадная машина | siege_machine | Осадные машины, такие как катапульты (которые следовало бы называть баллистами)                                                  |
| Монстр         | monster       | Существа, такие как Замороженный робот (который следовало бы называть Ледяным големом), Энт, Демон и Боевой демон                |
