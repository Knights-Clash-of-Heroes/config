# Тип атрибута

Тип атрибута определяет поведение атрибута у юнита или здания, которому он принадлежит.

| Название     | Значение      | Описание                                                                         |
| ------------ | ------------- | -------------------------------------------------------------------------------- |
| Механический | `mechanical`  | Применяет прямое числовое значение к характеристике юнита                        |
| Аура         | `aura`        | Излучает постоянную пассивную ауру вокруг юнита, пока он жив                     |
| Описательный | `descriptive` | Не влияет на механику; используется только для отображения информации (лор/визуал) |
