# Направление

Перечисление Direction определяет пространственную ориентацию объектов и направление движения в игровом мире.

| Значение | Описание | Визуальное соответствие |
| -------- | -------- | ----------------------- |
| north    | Север    | Спереди                 |
| south    | Юг       | Сзади                   |
| east     | Восток   | Справа                  |
| west     | Запад    | Слева                   |
