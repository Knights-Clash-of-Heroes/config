# Тип орды

Тип орды определяет поведение юнитов, появляющихся на поле боя, по отношению к игроку и его юнитам.

| Название     | Значение | Описание                                                                       |
| ------------ | -------- | ------------------------------------------------------------------------------ |
| Мирная       | peaceful | Мирная или союзная орда, юниты не атакуют юнитов игрока                        |
| Враждебная   | hostile  | Враждебная орда, юниты атакуют юнитов игрока и его строения                    |
