# Тип стоимости

Тип стоимости определяет необходимый предмет:

| Название | Значение | Описание                                                                    |
| -------- | -------- | --------------------------------------------------------------------------- |
| Ресурс   | resource | Ресурсы, такие как золото, кристаллы, дерево, камень, железо, энергия и драгуны |
| Предмет  | item     | Предметы, такие как кожаные туники, инженерные чертежи, алебарды и т. д.    |
