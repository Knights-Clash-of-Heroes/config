# Триггер орды

Триггер орды определяет условие или момент, при котором орда появляется во время матча.

| Название              | Значение        | Описание                                                          |
| --------------------- | --------------- | ----------------------------------------------------------------- |
| Босс побеждён         | boss_defeated   | Орда появляется сразу после победы над боссом                     |
| После хода босса      | after_boss_turn | Орда появляется сразу после окончания хода босса                  |
| После диалога         | after_dialog    | Орда появляется в момент окончания диалога между персонажами      |
