# Аура

Интерфейс ауры определяет постоянный модификатор области, не имеющий длительности в ходах — он активен, пока излучающий его юнит находится на поле. Аура влияет на всех союзных юнитов в пределах её радиуса. Она всегда оказывает механическое воздействие.

> **Примечание:** Аура может излучаться временно через [эффект](effect.md) типа `aura`, который определяет, сколько ходов аура остаётся активной.

| Свойство        | Тип    | Описание                                           |
| --------------- | ------ | -------------------------------------------------- |
| aura_id         | int    | Идентификатор ауры (тип)                           |
| name            | string | Название ауры                                      |
| name_key        | string | Ключ перевода названия                             |
| description     | string | Описание ауры                                      |
| description_key | string | Ключ перевода описания                             |
| value           | int    | Значение механического воздействия ауры            |
| radius          | int    | Радиус в клетках вокруг излучающего юнита          |

## Пример определения

```json
{
    "aura_id": 1,
    "name": "Aura of Courage",
    "name_key": "aura_1_name",
    "description": "Increases the attack of nearby allied units.",
    "description_key": "aura_1_desc",
    "value": 15,
    "radius": 2
}
```
