# Позиция

Интерфейс Position используется для определения координат в системе сетки, например расположения участка земли на карте или позиции объекта.

| Свойство | Тип | Описание                          |
| -------- | --- | --------------------------------- |
| x        | int | Координата по горизонтальной оси  |
| y        | int | Координата по вертикальной оси    |

## Пример определения

```json
{
    "x": 1,
    "y": 1
}
```
