# Цены и стоимость

Интерфейс цены используется для определения стоимости чего-либо: здания, предмета, юнита, исследования и т. д.

| Свойство    | Тип                                    | Описание                                            |
| ----------- | -------------------------------------- | --------------------------------------------------- |
| type        | [enum:CostType](../enums/cost-type.md) | Тип цены                                            |
| resource_id | int \| null                            | Идентификатор ресурса, если тип — `resource`        |
| item_id     | int \| null                            | Идентификатор предмета, если тип — `item`           |

## Пример определения

```json
{
    "type": "resource",
    "resource_id": 1,
    "quantity": 10
}
```
