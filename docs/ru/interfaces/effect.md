# Эффект

Интерфейс эффекта определяет модификатор с гарантированным механическим воздействием, применяемый к юниту. Каждый эффект должен иметь название и описание для отображения в интерфейсе.

Существует два типа эффектов, определяемых полем `type`:

- **`temporary`**: действует заданное число ходов и влияет только на целевой юнит.
- **`aura`**: сам по себе не длится несколько ходов — он активирует [ауру](aura.md) вокруг излучающего юнита на несколько ходов. Выгоду получают ближайшие союзные юниты (в радиусе ауры).

## Общие свойства (все типы)

| Свойство        | Тип    | Описание                                   |
| --------------- | ------ | ------------------------------------------ |
| effect_id       | int    | Идентификатор эффекта (тип)                |
| type            | [enum:EffectType](../enums/effect-type.md) | Тип эффекта: `temporary` или `aura` |
| name            | string | Название эффекта                           |
| name_key        | string | Ключ перевода названия                     |
| description     | string | Описание эффекта                           |
| description_key | string | Ключ перевода описания                     |

## Свойства только для типа `temporary`

| Свойство | Тип | Описание                                     |
| -------- | --- | -------------------------------------------- |
| value    | int | Значение механического воздействия на цель   |
| duration | int | Число ходов, в течение которых действует эффект |

## Свойства только для типа `aura`

| Свойство | Тип | Описание                                                      |
| -------- | --- | ------------------------------------------------------------- |
| aura_id  | int | Идентификатор [ауры](aura.md), которая будет излучаться       |
| duration | int | Число ходов, в течение которых аура активна вокруг излучателя |

## Пример — тип `temporary`

```json
{
    "effect_id": 1,
    "type": "temporary",
    "name": "Fury",
    "name_key": "effect_1_name",
    "description": "Temporarily increases the damage dealt.",
    "description_key": "effect_1_desc",
    "value": 50,
    "duration": 3
}
```

## Пример — тип `aura`

```json
{
    "effect_id": 3,
    "type": "aura",
    "name": "Battle Cry",
    "name_key": "effect_3_name",
    "description": "The hero inspires nearby soldiers, activating an aura of courage for 2 turns.",
    "description_key": "effect_3_desc",
    "aura_id": 1,
    "duration": 2
}
```
