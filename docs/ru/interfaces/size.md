# Размер

Интерфейс размера — это определение ширины и длины объекта: юнита, героя, здания, декорации или постройки королевства.

| Свойство | Тип | Описание |
| -------- | --- | -------- |
| x        | int | Ширина   |
| y        | int | Длина    |

## Пример определения

```json
{
    "width": 1,
    "height": 1
}
```
