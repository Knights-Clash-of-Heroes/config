# Увеличение хранилища

Интерфейс увеличения хранилища используется для определения дополнительной вместимости, которую здание (например, хранилище) даёт для конкретного ресурса в королевстве игрока.

| Свойство    | Тип | Описание                                                                       |
| ----------- | --- | ------------------------------------------------------------------------------ |
| resource_id | int | Идентификатор ресурса, вместимость которого будет увеличена                    |
| quantity    | int | Количество, которое будет добавлено к общей вместимости хранилища этого ресурса |

## Пример определения

```json
{
    "resource_id": 1,
    "quantity": 10000
}
```
