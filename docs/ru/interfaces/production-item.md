# Производимый предмет

Интерфейс Production Item используется для определения производства предмета в здании.

| Свойство    | Тип значения | Описание                            | Пример значения |
| ----------- | ------------ | ----------------------------------- | --------------- |
| type        | string       | Тип производства                    | "resource"      |
| resource_id | int          | Идентификатор ресурса               | 1               |
| quantity    | int          | Произведённое количество            | 1               |
| time        | int          | Время производства в секундах       | 1               |
| limit       | int          | Лимит производимых предметов        | 100             |

## Пример определения

```json
{
    "type": "resource",
    "resource_id": 1,
    "quantity": 1,
    "time": 1,
    "limit": 100
}
```
