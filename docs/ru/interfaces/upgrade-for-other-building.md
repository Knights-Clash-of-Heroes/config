# Улучшение для других зданий (UpgradeForOtherBuilding)

Интерфейс `UpgradeForOtherBuilding` — упрощённая версия улучшения здания, используемая, когда улучшение влияет на здания, отличные от основного. Он имеет ту же базовую структуру, но не содержит свойств стоимости, времени улучшения и рекурсии.

| Свойство    | Тип значения                                | Описание                                                                                                           | Пример значения                                  |
| ----------- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------ |
| building_id | int                                         | Идентификатор здания, которое получит улучшение                                                                    | 1                                                |
| stats       | [interface:Stats](./stats.md)               | Боевые характеристики, применяемые к зданию                                                                        | [Определение](./stats.md#definition-example)     |
| attributes  | [array:interface:Attribute](./attribute.md) | Дополнительные атрибуты (пассивные). Если применяется несколько атрибутов одного типа, их значения суммируются.     | [Определение](./attribute.md#definition-example) |

## Пример определения

```json
{
    "building_id": 1,
    "stats": {
        "health": 10,
        "attack": null,
        "initiative": null,
        "speed": null,
        "range": null
    },
    "attributes": [
        {
            "attribute_id": 1,
            "value": 5
        }
    ]
}
```
