# Боевые характеристики (Stats)

| Свойство   | Тип         | Описание                                 |
| ---------- | ----------- | ---------------------------------------- |
| health     | int         | Здоровье юнита                           |
| attack     | int \| null | Урон атаки юнита                         |
| initiative | int \| null | Инициатива юнита                         |
| speed      | int \| null | Радиус шага юнита                        |
| range      | int \| null | Дальность атаки снарядами юнита          |

## Пример определения

```json
{
    "health": 100,
    "attack": 25,
    "initiative": 100,
    "speed": 3,
    "range": null
}
```
