# Юнит орды

Интерфейс юнита орды используется для определения части состава орды: он указывает, какой юнит должен появиться и в какой позиции на карте.

| Свойство          | Тип                                                 | Описание                                                                                                                                                                |
| ----------------- | --------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| unit_id           | int                                                 | Идентификатор юнита, входящего в орду                                                                                                                                   |
| initial_position  | [interface:Position](./position.md) \| "random"     | Начальная позиция (x, y) юнита. Если значение координаты равно `"random"`, позиция генерируется случайно в радиусе 7 клеток от центра орды.                              |
| target_position   | [interface:Position](./position.md) \| null         | Целевая позиция (x, y), к которой юнит автоматически направится после появления. Если null, ведёт себя как обычно.                                                       |
| custom_stats      | [interface:Stats](./stats.md) \| null               | Боевые характеристики юнита (здоровье, урон, инициатива и т. д.), переопределяющие исходные значения базового юнита                                                      |
| custom_attributes | [array:interface:Attribute](./attribute.md) \| null | Пассивные и активные способности, переопределяющие атрибуты исходного юнита                                                                                             |
| level_factor      | float \| null                                       | Множитель характеристик (таких как здоровье и урон) в зависимости от текущего уровня игрока, чтобы сложность орды росла постепенно                                      |

## Пример определения

```json
{
    "unit_id": 5,
    "initial_position": {
        "x": 10,
        "y": 12
    },
    "target_position": {
        "x": 15,
        "y": 15
    },
    "custom_stats": {
        "health": 150,
        "attack": 25,
        "initiative": 5,
        "speed": 3,
        "range": 1
    },
    "custom_attributes": [
        {
            "attribute_id": 1,
            "value": 15
        }
    ],
    "level_factor": 1.5
}
```
