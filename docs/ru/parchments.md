# Свитки

Свитки — расходуемые предметы, позволяющие игроку применить определённое заклинание без траты рун. Каждый свиток связан с одним заклинанием и расходуется после использования.

| Свойство | Тип    | Описание                                          |
| -------- | ------ | ------------------------------------------------- |
| id       | int    | Уникальный идентификатор свитка.                  |
| spell_id | int    | Идентификатор заклинания, которое содержит свиток. |
| name     | string | Название свитка.                                  |
| name_key | string | Ключ названия свитка (i18n).                      |

## Пример определения

```json
{
    "id": 1,
    "spell_id": 1,
    "name": "Earthquake Parchment",
    "name_key": "parchment_1_name"
}
```
