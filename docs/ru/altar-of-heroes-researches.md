# Исследования Алтаря героев

Исследования Алтаря героев (`altar_of_heroes_researches`) используются для улучшения героев: повышения их характеристик и усиления для сражений, а также для открытия новых героев. Они стоят игровых ресурсов и предметов, аналогично Арсеналу.

| Свойство        | Тип                                            | Описание                                                                                | Пример значения     |
| --------------- | ---------------------------------------------- | --------------------------------------------------------------------------------------- | ------------------- |
| id              | int                                            | Уникальный идентификатор исследования.                                                  | 1                   |
| name            | string                                         | Название исследования.                                                                  | "Majestic Training" |
| name_key        | string                                         | Ключ перевода названия.                                                                 | "altar_1_name"      |
| price           | [array:interface:Price](./interfaces/price.md) | Необходимая стоимость в ресурсах и предметах.                                           | [...]               |
| research_time   | int                                            | Время завершения исследования в секундах.                                               | 3600                |
| hero_upgrade_id | int \| null                                    | ID улучшения героя (`hero_upgrades`), активируемого этим исследованием.                 | 1                   |
| unlock_hero_id  | int \| null                                    | ID нового открываемого героя (`heroes`), если исследование нанимает/открывает героя.    | null                |

## Пример определения

```json
{
    "id": 1,
    "name_key": "altar_research_1_name",
    "name": "Royal Training",
    "price": [
        {
            "type": "resource",
            "resource_id": 1,
            "quantity": 500
        }
    ],
    "research_time": 3600,
    "hero_upgrade_id": 1,
    "unlock_hero_id": null
}
```
