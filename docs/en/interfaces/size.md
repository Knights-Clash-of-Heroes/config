# Size

The size interface is the definition of the width and length of an object, be it a unit, a hero, a building, a decoration, or a kingdom building.

| Property | Type | Description |
| -------- | ---- | ----------- |
| x        | int  | Width       |
| y        | int  | Length      |

## Definition example

```json
{
    "width": 1,
    "height": 1
}
```
