# Combat properties (Stats)

| Property   | Type        | Description                              |
| ---------- | ----------- | ---------------------------------------- |
| health     | int         | Health of the unit                       |
| attack     | int \| null | Attack damage of the unit                |
| initiative | int \| null | Initiative of the unit                   |
| speed      | int \| null | Step range radius of the unit            |
| range      | int \| null | Projectile attack range of the unit      |

## Definition example

```json
{
    "health": 100,
    "attack": 25,
    "initiative": 100,
    "speed": 3,
    "range": null
}
```
