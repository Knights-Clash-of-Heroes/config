# Position

The Position interface is used to define coordinates in a grid system, such as the location of a land chunk on the map or the position of an object.

| Property | Type | Description                  |
| -------- | ---- | ---------------------------- |
| x        | int  | Coordinate on the horizontal axis |
| y        | int  | Coordinate on the vertical axis   |

## Definition example

```json
{
    "x": 1,
    "y": 1
}
```
