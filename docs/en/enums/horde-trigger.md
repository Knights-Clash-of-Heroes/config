# Horde trigger

The horde trigger defines the condition or moment at which the horde is triggered during the match.

| Name              | Value           | Description                                                       |
| ----------------- | --------------- | ----------------------------------------------------------------- |
| Boss defeated     | boss_defeated   | The horde spawns as soon as a boss is defeated                    |
| After a boss turn | after_boss_turn | The horde spawns right after the end of a boss's turn             |
| After dialogue    | after_dialog    | The horde spawns the moment a dialogue between characters ends    |
