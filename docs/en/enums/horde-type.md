# Horde type

The horde type determines the behavior of the units that spawn on the battlefield toward the player and their units.

| Name     | Value    | Description                                                                    |
| -------- | -------- | ------------------------------------------------------------------------------ |
| Peaceful | peaceful | Peaceful or allied horde, the units do not attack the player's units           |
| Hostile  | hostile  | Hostile horde, the units will attack the player's units and their structures   |
