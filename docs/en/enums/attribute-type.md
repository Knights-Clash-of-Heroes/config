# Attribute type

The attribute type defines the behavior the attribute will have on the unit or building that carries it.

| Name        | Value         | Description                                                                      |
| ----------- | ------------- | -------------------------------------------------------------------------------- |
| Mechanical  | `mechanical`  | Applies a direct numeric value to a stat of the unit                             |
| Aura        | `aura`        | Emits a continuous passive aura around the unit while it is alive                |
| Descriptive | `descriptive` | No mechanical impact; only used to display information (lore/visual)             |
