# Attack type

The attack type is used to trigger the attacker's abilities and passives and the passive negative effects on the target, and can be:

| Name        | Value | Description                                                                                          |
| ----------- | ----- | ---------------------------------------------------------------------------------------------------- |
| Melee       | melee | Physical attack, usually dealt by heavy infantry troops and armored units                            |
| Arrow       | arrow | Bow and arrow attack, dealt by archers and archer towers                                             |
| Siege       | siege | Dart attack, dealt by ballistas                                                                      |
| Magic       | magic | Magic attack, dealt by mages, both those who fire projectiles and those who attack in melee          |
