# Target type

The target type defines whether a spell, ability, unit or building hits a single target, an area or a chain of targets:

| Name   | Value  | Description                                                                                                       |
| ------ | ------ | ----------------------------------------------------------------------------------------------------------------- |
| Single | single | Hits only one target, available for units, buildings and spells                                                   |
| Area   | area   | Hits an area, available for units, buildings and spells; the range value must be odd so that it has a center      |
| Chain  | chain  | Hits a chain of targets, available only for spells                                                                |
