# Unit type

The unit type is a categorization that defines what the unit is, in order to infer whether or not it can be affected by active and passive abilities:

| Name          | Value         | Description                                                                                                                      |
| ------------- | ------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| On foot       | on_foot       | Soldier on foot, usually heavy infantry, some armored units, mages                                                               |
| Mounted       | mounted       | Mounted soldier, usually on a horse; includes all knights and other soldiers mounted on animals such as the snow leopard        |
| Siege machine | siege_machine | Siege machines such as catapults (which should be called ballistas)                                                              |
| Monster       | monster       | Creatures such as the Frozen Robot (which should be called Ice Golem), Ent, Demon and War Demon                                  |
