# Effect type

The effect type defines how the mechanical impact will be applied.

| Name      | Value       | Description                                                                                          |
| --------- | ----------- | ---------------------------------------------------------------------------------------------------- |
| Temporary | `temporary` | Lasts a set number of turns and affects only the target unit.                                        |
| Aura      | `aura`      | Activates an [Aura](../interfaces/aura.md) around the emitting unit for a number of turns.           |
