# Kingdom Settings

This file defines the global properties of the player's kingdom that are not tied to a specific entity or that serve as a starting value (baseline).

| Property                 | Type | Description                                                                 | Example value |
| ------------------------ | ---- | --------------------------------------------------------------------------- | ------------- |
| initial_occupation_limit | int  | The initial occupation (housing) limit the kingdom supports for units.      | 10            |

## Definition example

```json
{
    "initial_occupation_limit": 8
}
```
